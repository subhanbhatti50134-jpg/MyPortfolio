# Subhan Bhatti React Portfolio

Converted from the supplied `index.html` into a Vite + React project.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Assets

Place the original portfolio assets here:

- `public/assets/subhan.jpg` — hero/profile image
- `public/assets/Subhan_Bhatti_CV_ATS_v2.pdf` — resume

The supplied HTML referenced these files, but they were not part of the uploaded `index.html`, so they are not included in this conversion.
